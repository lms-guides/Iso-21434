FreeRTOSConfig.h: the contract

Every behaviour you will later debug is decided in one header. Read it as a design document, not as boilerplate copied from a demo.

  • Configuration
  • Heap size
  • Tick rate
  • NVIC ceiling

By the end of this module

  • Read and justify the twenty config values that actually matter.
  • Distinguish word-based stack sizes from byte-based heap sizes.
  • Derive the interrupt priority ceiling from your MCU's implemented priority bits.

A config you can defend

This is a reasonable starting point for a Cortex-M3/M4/M7 product. Every commented line is a decision, not a default.

#ifndef FREERTOS_CONFIG_H
#define FREERTOS_CONFIG_H

/* ---------------- Scheduler ---------------- */
#define configUSE_PREEMPTION                     1  /* 1 in virtually all products */
#define configUSE_TIME_SLICING                   1  /* equal priorities round-robin */
#define configUSE_PORT_OPTIMISED_TASK_SELECTION  1  /* CLZ-based; max 32 priorities */
#define configMAX_PRIORITIES                     8  /* 0..7, higher number = urgent */
#define configTICK_RATE_HZ                       1000 /* 1 ms tick */
#define configCPU_CLOCK_HZ                       (SystemCoreClock)

/* ---------------- Memory ---------------- */
#define configSUPPORT_DYNAMIC_ALLOCATION         1
#define configSUPPORT_STATIC_ALLOCATION          0
#define configTOTAL_HEAP_SIZE                    (24 * 1024)  /* bytes (heap_4) */
#define configMINIMAL_STACK_SIZE                 128    /* WORDS, not bytes */
#define configSTACK_DEPTH_TYPE                   uint16_t

/* ---------------- Objects ---------------- */
#define configUSE_MUTEXES                        1
#define configUSE_RECURSIVE_MUTEXES              1
#define configUSE_COUNTING_SEMAPHORES            1
#define configUSE_TASK_NOTIFICATIONS             1
#define configTASK_NOTIFICATION_ARRAY_ENTRIES    2
#define configQUEUE_REGISTRY_SIZE                8

/* ---------------- Software timers ---------------- */
#define configUSE_TIMERS                         1
#define configTIMER_TASK_PRIORITY                (configMAX_PRIORITIES - 1)
#define configTIMER_QUEUE_LENGTH                 10
#define configTIMER_TASK_STACK_DEPTH             256

/* ---------------- Hooks and diagnostics ---------------- */
#define configUSE_IDLE_HOOK                      1
#define configUSE_TICK_HOOK                      0
#define configCHECK_FOR_STACK_OVERFLOW           2
#define configUSE_MALLOC_FAILED_HOOK             1
#define configUSE_TRACE_FACILITY                 1
#define configUSE_STATS_FORMATTING_FUNCTIONS     1
#define configGENERATE_RUN_TIME_STATS            0   /* enable in Module 12 */
#define configASSERT(x) \
    if ((x) == 0) { taskDISABLE_INTERRUPTS(); for (;;) { } }

/* ---------------- Cortex-M interrupt priorities ---------------- */
#define configPRIO_BITS                          4   /* check your MCU: 3..8 */
#define configLIBRARY_LOWEST_INTERRUPT_PRIORITY      15
#define configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY 5
#define configKERNEL_INTERRUPT_PRIORITY \
    (configLIBRARY_LOWEST_INTERRUPT_PRIORITY << (8 - configPRIO_BITS))
#define configMAX_SYSCALL_INTERRUPT_PRIORITY \
    (configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY << (8 - configPRIO_BITS))

/* ---------------- Trim the API surface ---------------- */
#define INCLUDE_vTaskPrioritySet                1
#define INCLUDE_uxTaskPriorityGet               1
#define INCLUDE_vTaskDelete                     1
#define INCLUDE_vTaskSuspend                    1
#define INCLUDE_xTaskDelayUntil                 1
#define INCLUDE_vTaskDelay                      1
#define INCLUDE_xTaskGetSchedulerState          1
#define INCLUDE_xTaskGetCurrentTaskHandle       1
#define INCLUDE_uxTaskGetStackHighWaterMark     1
#endif

The three lines people get wrong

  1. Stack depth is in words. On Cortex-M, 256 means 256 StackType_t, i.e. 1024 bytes. configMINIMAL_STACK_SIZE and usStackDepth are words; configTOTAL_HEAP_SIZE is bytes. Check portSTACK_TYPE in portmacro.h if a port surprises you.
  2. The heap size is bytes and only applies to heap_1/2/4/5. With heap_3 it is ignored — the C library heap in your linker script is what matters instead.
  3. The syscall ceiling must be derived from implemented priority bits. Hard-coding 0x50 works on a 4-bit part and fails silently on a 3-bit one. The macros above produce 0x50 for 4 bits and 0xA0 for 3.
Unit trap

A 512-word stack is 2 KB. On a 20 KB RAM part, five of those plus a 24 KB heap will not link — and if the heap is in internal RAM via a linker section, the failure appears as a weird reset rather than a compile error. Write the budget down before the build does it for you.

What each family of options costs

configUSE_TIMERSYou want debounce, timeouts or periodic callbacks without a taskOne task, one queue, stack from the heap

Hooks are not optional in development

void vApplicationStackOverflowHook(TaskHandle_t xTask, char *pcTaskName)
{
    (void)xTask;
    taskDISABLE_INTERRUPTS();
    panic_log("stack overflow: %s", pcTaskName);
    for (;;) { }
}

void vApplicationMallocFailedHook(void)
{
    taskDISABLE_INTERRUPTS();
    panic_log("kernel allocation failed");
    for (;;) { }
}

void vApplicationIdleHook(void)
{
    __WFI();   /* sleep until the next interrupt; remove if you measure spin */
}

An assert that stops the board with the task name on a UART or in a retained RAM buffer is worth more than a week of print-statement debugging. In production, replace the infinite loop with a logged reset — but keep the hook.

Lab: break the config on purpose

  1. Set configTOTAL_HEAP_SIZE to 2048 and create four 512-word tasks. Watch vTaskStartScheduler() return, then make the malloc hook print.
  2. Set configCHECK_FOR_STACK_OVERFLOW to 0 and recurse inside a task until it corrupts a neighbour. Notice that nothing tells you what happened — that is the lesson.
  3. Print configMAX_SYSCALL_INTERRUPT_PRIORITY at boot and compare it with the NVIC_IPR width in your MCU reference manual.
Key takeaway

If you cannot explain why a config value has the number it has, it is a latent bug with a delay fuse. Twenty values, twenty justifications.
